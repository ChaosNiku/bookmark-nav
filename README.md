# 书签导航 · Bookmark Nav

整合自「奔跑中的奶酪 5000 实用网站」与个人浏览器书签的单页静态导航站。

- 49,541 个网站 / 6,438 个分类
- 纯静态单文件 `index.html`，零外部依赖，双击即可离线使用
- 左侧分类树（整行点击展开）+ 主区分区块平铺 + 全文搜索高亮
- 最近访问记录、随机漫游、明暗主题、移动端适配

## 本地使用

直接双击 `index.html`，或任意静态服务器托管：

```bash
npx serve .
```
